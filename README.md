# Crit

Crit is a local-first tool for arranging and assessing live web iterations.

The package is under active extraction from its first host application. The
eventual golden path is:

```sh
npx @riff-refine/crit init
```

The current implementation work starts with the platform-neutral Canvas engine
and filesystem/CLI tracer bullet. React, Vite, Cloudflare, and the bundled agent
skill follow through explicit package entry points.
